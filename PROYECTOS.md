# 📋 Proyectos de Datos y Docencia (Python)

Este archivo clasifica los recursos del repositorio y propone proyectos basados en palabras clave para su desarrollo futuro.

## 📊 Proyectos de Análisis de Datos

| Palabra Clave | Archivo(s) | Propósito del Proyecto | Visualización Propuesta |
| :--- | :--- | :--- | :--- |
| **`ANÁLISIS_SALARIOS`** | `Salaries.csv` | Estudiar la distribución salarial, promedios por cargo e identificar sesgos. | Boxplot y Histogramas (Seaborn). |
| **`PRONÓSTICOS_DATOS`** | `Pronosticos.csv`, `Pronosticos.xlsx` | Comparar predicciones vs. datos reales para medir precisión (MAE/MSE). | Gráfico de líneas (Predicho vs Real). |
| **`PERFILADO_CRUDO`** | `Insumo 2.csv`, `sajquies.csv` | Limpieza de datos nulos, duplicados y normalización de columnas. | Reporte de calidad de datos (Pandas Profiling). |
| **`PROCESO_TEXTO`** | `Datos.txt`, `Datos.py` | Extracción y estructuración de información desde archivos planos. | Conteo de frecuencias / Nube de palabras. |
